## Descrição
 
O objetivo é calcular o **consumo mensal estimado**  de um aparelho elétrico em kWh e o **custo estimado**  desse consumo, com base em uma tarifa de energia que varia conforme a região  do Brasil informada pelo usuário.

 ---
 
## Objetivo do Projeto
 
Praticar conceitos fundamentais de programação, como:
 
- 📥📤 Entrada e saída de dados (`input()` / `print()`)
- 🔀 Estruturas condicionais (`if` / `else`)
- 🔁 Estrutura de repetição (`while`)
- ✂️ Tratamento de strings (`.strip()`, `.capitalize()`)
- ✅ Validação de entrada do usuário

---
 
 ## Instruções de Uso

 1. Execute o arquivo calculadora_energia.py.
 2. Informe o aparelho, a potência, o tempo de uso diário e a região.

   > ⚠️ **Observação:** informe apenas os valores numéricos, **sem unidades de medida** (ex.: digite `150`, não `150W`; digite `24`, não `24h`).

3. Exemplo: Geladeira, 150, 24, Sudeste → o programa retorna o consumo (kWh) e o custo estimado (R$).
